### Live mode failure UX

`--live` failed on local Codex when `~/.codex/config.toml` used
`model = "gpt-5.6-sol"` against Codex CLI 0.142.0 ("requires a newer version").
Even after model override, ChatGPT usage limits can still block live runs.

Desk changes:
- structured `AgentAdapterError` JSON report with `codex_message` + hints
- `--model` / `--timeout` for live runs
- `--skip-git-repo-check` on live Codex command
- docs clarify offline is the default verified path

## Pi TUI command fix

`uv run loops-hlp-tui --adapter pi` failed with
`pi-harness.delegate: process command failed` because the default command was
the stale `("pi", "run", "--json")`. Current Pi CLI rejects `--json` and uses
`pi --mode json -p --no-session <prompt>`.

Fixed:
- `PiHarnessAdapter` default command aligned to current CLI
- TUI `render_error` now shows exit_code / command / stderr tail for adapter failures
