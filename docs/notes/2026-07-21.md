### What shipped (P0 + P1)

- **Ctrl+C → task.interrupt**: the REPL catches KeyboardInterrupt during
  live waits and raises a human interrupt checkpoint (task → blocked,
  resolvable) instead of killing the session. `_interrupt_active` helper,
  offline-tested.
- **`/tasks` + `/use <id>`**: task list with active marker; switch active
  task (terminal tasks rejected, unknown ids NOT_FOUND-rendered).
- **`/handoff <agent>`**: `ownership.transfer` through the controller;
  harness fork fires automatically on pi/claude — the receiving agent
  inherits full session context.
- **`/artifacts` + `/show <id>`**: delivery visibility before review.
- **Startup recovery**: `--resume <session_id>` jumps into a saved session;
  the banner always shows adapter/principal/session/open-inbox count and
  prints the open inbox.
- **Grouped `/help`** (Session / Tasks & artifacts / Human-loop decisions /
  Continuous control / Other) and **`--model`** passthrough
  (codex `-m`, pi/claude `--model`, kimi `-m`).
- Continuity flag stripping relaxed: `--no-session` /
  `--no-session-persistence` are now stripped with continuity on for ANY
  command (not just defaults), so custom commands (e.g. with `--model`)
  keep session resume working.
