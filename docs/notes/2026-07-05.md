# 2026-07-05

## HLP adapter outbox completion

- 扩展 `AdapterOperationContext` 覆盖剩余 outbound adapter side effect：
  `task.assign` delegate、`task.cancel`、`ownership.transfer` handoff 与
  `ownership.delegate`。
- `HumanLoopOperations` 不再直接调用 `delegate` / `cancel` / `handoff` /
  `steer` / `block` / `resume`；所有外部 side effect 先写入
  `AdapterOutboxRecord`，调用 adapter 时传递 `operation_context`，本地 mutation
  成功后标记 outbox `succeeded`。
- Fake、Process、Codex 以及 Python/framework adapter 的 delegate/handoff/cancel
  接口新增可选 operation context；Process/Codex JSON payload 携带
  `operation_context`，framework adapter 至少在本地调用记录中保留 wire context。
- conformance 新增 delegate/handoff/cancel operation context 传播与 process
  serialization 覆盖，和原有 steer/block/resume、SQLite restart pending outbox
  retry 覆盖一起构成完整 outbound adapter 边界证据。

## HLP reducer-ready audit payload

- `AuditEvent` 新增 `reducer` payload，保留原 `before` / `after` 字段不变。
- `HumanLoopOperations._audit()` 自动生成 canonical reducer payload：`subject`、
  当前 Task reducer snapshot（state、revision、ownership、checkpoint/artifact ids、
  steering count）和事件级 `change`。
- JSON schema、spec/site/conformance 文档与工业 profile 测试同步覆盖 reducer-ready
  audit payload，和已有 hash-chain 一起构成审计完整性与可回放证据。

## HLP Task CAS/idempotency breadth

- 将 `expected_task_revision` CAS 与 task-scoped `idempotency_key` replay 从原先
  `task.amend`、`task.interrupt`、`checkpoint.resolve`、`artifact.commit` 扩展到所有会推进
  现有 `Task.revision` 的 Task aggregate mutation：`task.assign`、`task.start`、
  `task.cancel`、`checkpoint.raise`、`checkpoint.expire`、`ownership.transfer`、
  `ownership.delegate` 与 `review.submit`。
- 这些 mutation 统一通过 `_begin_task_operation` / `_commit_task_operation` 生成 canonical
  request fingerprint、稳定 operation id、idempotency replay 记录和 adapter outbox 成功标记；
  写入 idempotency record 时会 flush 可持久化 store。
- SDK facade 的 `delegate`、`start`、`raise_checkpoint` 与 `submit_review` 暴露同样的可选
  CAS/idempotency 参数，并在 replay 时不重复发布 SDK event。
- conformance 新增 assign/start/cancel/checkpoint raise/expire/ownership transfer/ownership
  delegate/review submit replay 覆盖，SDK 测试新增 primary mutation replay 事件去重覆盖。
- 修复 SDK 延迟 replay 返回当前 store 状态的问题：adapter outbox 成功记录现在保存返回值（如
  delegate/handoff run id），SDK facade 在 replay 分支返回首次 operation 结果快照，
  不再重新读取已经被后续 mutation 改变的 Task/Checkpoint。
