# 2026-07-05

## HLP adapter outbox completion

- 扩展 `AdapterOperationContext` 覆盖剩余 outbound adapter side effect：
  `task.assign` delegate、`task.cancel`、`ownership.transfer` handoff 与
  `ownership.delegate`。
- `HumanLoopOperations` 不再直接调用 `delegate` / `cancel` / `handoff` /
  `steer` / `block` / `resume`；所有外部 side effect 先写入
  `AdapterOutboxRecord`，调用 adapter 时传递 `operation_context`，本地 mutation
  成功后标记 outbox `succeeded`。
- Fake、Process、Codex 以及 Python/framework adapter 的 delegate/handoff/cancel
  接口新增可选 operation context；Process/Codex JSON payload 携带
  `operation_context`，framework adapter 至少在本地调用记录中保留 wire context。
- conformance 新增 delegate/handoff/cancel operation context 传播与 process
  serialization 覆盖，和原有 steer/block/resume、SQLite restart pending outbox
  retry 覆盖一起构成完整 outbound adapter 边界证据。
