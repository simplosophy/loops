# 2026-07-04 变更记录

## HLP 工业级协议审计与 0.2.0 参考实现硬化

### 审计结论

对 HLP 做了四路并行只读审计：
- 协议规范与 conformance 文档
- `loops.hlp` 核心参考实现
- SDK facade、adapters 与 examples
- 文档站点、发布验证与测试矩阵

主要结论：HLP-first 架构边界正确，但 `docs/specs/HLP.md` 已声明
0.2.0-draft 连续控制语义，参考实现仍缺 `task.interrupt`、`task.amend`、
`steering_log`、`AgentAdapter.steer`、partial approval、`state_patch` 和
`Review.kind` 等关键能力。当前测试全绿只能证明旧闭环自洽，不能证明
0.2.0 conformance。

### 执行策略

新增 `docs/plans/2026-07-04-hlp-industrial-hardening.md`，分三阶段推进：
1. 先让 0.2.0 reference implementation 可执行。
2. 再新增可机器运行的 conformance suite 与发布验证。
3. 最后定义工业 profile：CAS、idempotency、durable outbox、hash-chain audit、
   schema 与 version negotiation。

本轮先执行 Phase 1，避免把 HLP SDK 扩成 agent harness 或服务端平台。

  claim 的离线验证入口：`uv run pytest tests/conformance -q`。
- 新增 `tests/conformance/test_hlp_compatible_profile.py`，覆盖 7 个一等对象、
  0.2.0 值对象、23 个操作、连续控制、状态机正负例、不可变性、audit query/replay
  和 golden flow。
- 新增 `tests/conformance/test_hlp_integrated_profile.py`，覆盖 harness event 投影、
  run/task correlation 校验、resume payload 和 process adapter fail-fast。
- 同步 `docs/site/conformance.md`、`docs/specs/HLP.md`、`docs/site/specs/hlp.md`：
  0.2.0 仍是 draft，但核心语义现在由参考实现和离线 conformance suite 覆盖。

### Release verification

## HLP 版本常量与错误对象 wire shape

- 新增公开版本常量：`HLP_SPEC_VERSION = "0.2.0-draft"` 与
  `HLP_SCHEMA_VERSION = "0.2"`，从 `loops` / `loops.hlp` 导出。
- 扩展 `ProtocolError`：支持 `details`、`retryable` 和 `to_dict()`，输出稳定
  wire object：`code/message/details/retryable/operation_id/correlation_id/spec_version/schema_version`。
- 默认 retryable 策略：`CONFLICT` / `DEADLINE_EXCEEDED` 可重试，其余协议错误默认
  不可重试；transport 或 adapter 可显式覆盖。
- 同步 `docs/specs/HLP.md` 与 `docs/site/specs/hlp.md` 的 Errors 章节，并让
  release metadata / spec-site sync 脚本检查版本常量和错误对象 token。

## HLP reliable harness event delivery

- 新增 `HarnessEventDelivery(cursor, event)` 与可选 `ReliableHarnessEventAdapter`
  扩展：`peek_events(run_id, cursor?, limit?)` 非破坏式读取，`ack_events(run_id,
  through)` 确认同一 run 内事件前缀。
- `FakeHarnessAdapter` 与 `CodexHarnessAdapter` 支持 peek/ack；legacy
  `observe(run_id)` 仍保留为读取即消费的兼容接口。
- `HLPClient.project_harness_events` 优先使用 peek/ack，只有成功投影 checkpoint /
  artifact 后才 ack；correlation 或 precondition 失败时保留未确认事件。
- conformance 增加 integrated profile 覆盖：投影失败不丢事件、cursor ack 按 run
  前缀前进。
- 文档明确：`HLP-compatible` / `HLP-integrated` 不等同于 `HLP-industrial`。
  CAS、idempotency、durable outbox、reducer-ready audit、permission grammar、
  schema 与 version negotiation 仍是后续工业 profile 工作。

## HLP task CAS 与 idempotency reference slice

- `Task` 新增 `revision`，初始为 0；成功的 Task aggregate mutation 让 revision
  只前进一次。
- mutating operation 支持 `expected_task_revision` 和 task-scoped
  `idempotency_key`：stale revision 在 adapter 调用前返回 `CONFLICT`；同 key 同
  canonical request fingerprint 返回首次结果，不重复 precondition、adapter、audit
  或 SDK event。
- 当前 reference slice 覆盖 `task.amend`、`task.interrupt`、
  `checkpoint.resolve`、`artifact.commit`，并新增
  `tests/conformance/test_hlp_industrial_profile.py`。
- SQLite snapshot store 持久化 idempotency records；重启后同 key replay 不重复
  `steer` 或 SDK event publish。
- 新增 `AdapterOperationContext` 与 `AdapterOutboxRecord`，HLP 在 adapter
  side effect 前持久化 outbox intent，向 `steer` / `block` / `resume` 传入稳定
  `operation_context`，本地提交成功后将 outbox record 标记为 `succeeded`。

## HLP permission scope grammar

- 新增 `loops.hlp.permissions`：`normalize_permission_scope`、
  `permission_scope_matches`、`is_permission_scope_pre_authorized`。
- `PermissionGrant.scope` 与 `ProposedAction.permission_scope` 构造时会 trim/normalize
  并校验 grammar：`*` 或 `<namespace>:<target>`，通配符只允许作为后缀。
- 授权判断忽略过期 grant；active matching deny 优先于 active matching allow；没有
  active allow 时视为未预授权。
- conformance 覆盖 scope grammar、wildcard matching、expiry、deny precedence 和
  proposed action permission scope。

## HLP audit hash-chain

- `AuditEvent` 增加 `schema_version`、`profile`、`prev_hash`、`hash` 字段。
- `AuditLog.append` 按 canonical JSON（不含 `hash` 字段）计算 `sha256:` hash，并将
  `prev_hash` 指向上一条事件 hash。
- 新增 `AuditLog.verify_hash_chain()`；conformance 覆盖正常链验证和篡改检测。

## HLP JSON Schema 与 version negotiation

- 新增 `loops.hlp.schema`：`HLP_JSON_SCHEMAS`、`schema_for`、`to_wire`、
  `validate_wire_object`、`negotiate_hlp_version`、`VersionNegotiationResult`。
- `ProtocolError.to_dict()` 增加 `profile = "HLP-industrial"`，错误码增加
  `VERSION_UNSUPPORTED`。
- schema registry 覆盖一等对象与核心 wire object：`Task`、`Checkpoint`、
  `Ownership`、`Review`、`Artifact`、`Ledger`、`ProtocolError`、`AuditEvent`、
  `HarnessEvent`、`HarnessEventDelivery`、`PermissionGrant`、`ProposedAction`、
  `AdapterOperationContext`、`AdapterOutboxRecord`、`VersionNegotiation`。
- version negotiation 对 `spec_version`、`schema_version`、`profile` 无共同版本时
  fail fast 返回 `VERSION_UNSUPPORTED`。
