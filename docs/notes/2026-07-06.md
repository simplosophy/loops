# 2026-07-06

## HLP real adapter E2E

- Public demo 和 quickstart 从 fake adapter 默认路径迁到显式真实 adapter：
  `loops-hlp-demo` 默认走 Codex CLI adapter；README 与站点 SDK quickstart 使用
  `CodexCLIAdapter`；harness wrapping demo 使用 `CodexHarnessAdapter`。
- `examples/hlp_local_cli_e2e.py` 从 delegate smoke 扩展为完整 lifecycle：create、
  delegate、start、amend、checkpoint raise/resolve、artifact commit、review submit、
  ledger write、audit replay，并增加 handoff/cancel control path。
- 本地 CLI E2E 支持 `--adapters codex,kimi,claude`、`--timeout` 和 `--strict`；每个
  adapter 返回结构化 status、task/run/correlation、adapter operations、最终 task
  状态、review/ledger/audit，以及 error/details。
- 新增 opt-in external CLI E2E：未设置 `HLP_RUN_EXTERNAL_CLI_E2E=1` 时跳过；设置后
  Codex/Kimi/Claude 命令缺失、认证失败或非 `ok` payload 都会成为测试失败。
- `FakeAgentAdapter` 与 `FakeHarnessAdapter` 保持兼容导出，但文档定位为单元测试、
  离线合约探针和 failure injection fixture。
